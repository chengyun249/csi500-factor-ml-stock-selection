# 股票截面多因子 + 机器学习选股项目报告初稿

## 第一章 研究问题与项目设计

本文研究中证500成分股内部的截面选股问题。策略逻辑为：在每个月末，根据当时可获得的行情、估值、流动性和财务质量因子，对当月中证500历史成分股进行截面打分排序，并在下一交易日买入预测分数最高的一组股票，持有至下一次调仓。

本项目的核心目标不是简单寻找一个高收益回测结果，而是系统检验：

```text
1. 哪些截面因子在中证500股票池中具有稳定预测能力；
2. 机器学习模型是否能优于线性模型和强单因子；
3. 因子和模型表现是否依赖行业或风格暴露；
4. 财务质量因子是否提供额外信息；
5. 排序指标 IC 能否转化为组合收益。
```

## 第二章 数据与样本构建

本文使用 Tushare 获取数据，覆盖 2018-2024 年中证500历史成分股。使用历史成分股而非当前成分股，可以降低幸存者偏差。

原始数据包括：

```text
1. 中证500历史成分股权重；
2. 个股日频 OHLCV；
3. 个股复权因子；
4. 个股估值和市值数据；
5. 中证500价格指数和全收益指数；
6. fina_indicator 财务指标。
```

最终基准统一为中证500全收益指数 `h00905.CSI`。相较价格指数，全收益指数纳入分红再投资收益，因此对策略超额收益的衡量更严格。

## 第三章 因子构建

基础因子包括动量、低波动、低换手、价值和市值：

```text
ret_20_ex5
ret_60_ex5
low_vol
low_turnover
bp
log_mv
```

财务质量因子包括：

```text
fin_roe_dt
fin_grossprofit_margin
fin_netprofit_margin
fin_ocf_quality
fin_debt_to_assets_neg
fin_netprofit_yoy
```

所有财务数据均使用公告日 `ann_date` 做 point-in-time 对齐，规则为：

```text
ann_date <= signal_date - 1 day
```

这避免了将尚未公告的财务数据提前用于历史信号。

## 第七章 稳健性检验

### 7.1 行业中性化检验

行业中性化的目的是判断原始策略收益是否依赖行业暴露。结果显示，低波动因子在行业中性化后仍有较强组合表现，说明低波动效应并非完全来自行业配置。

行业中性化与原始 LightGBM Top50 年化超额均为负，说明正Rank IC没有稳定转化为头部组合收益，不能把模型排序能力直接解释成可交易alpha。

### 7.2 财务质量因子增强

财务质量因子在单因子层面表现不强，但在行业中性化 LightGBM 中改善了一部分 IC。然而，组合回测显示该改善并没有稳定转化为更高收益。财务增强 LightGBM 的组合表现弱于原始 LightGBM 和低波动单因子。

### 7.3 成本敏感性

项目测试了 0bp、10bp、15bp、20bp、30bp 成本档。结果显示，换手较高的模型策略对交易成本更敏感，而部分单因子策略，尤其 BP 和低换手，换手相对较低。

## 第八章 结论

本文最终结论如下：

```text
1. 低波动是当前样本中最有希望的候选来源，但 23 个测试月不足以确认可部署 alpha；
2. LightGBM 的排序 IC 高于 Ridge，但没有转化为正的成本后绝对组合收益；
3. 行业中性化后，LightGBM 组合收益明显下降，说明其收益部分来自行业或风格暴露；
4. 财务质量因子改善了部分 IC，但未能稳定提升组合收益；
5. 当前因子库下，机器学习更多体现为对已有风格因子的整合，而不是创造独立新 alpha。
```

## 第九章 局限与后续方向

主要局限包括：

```text
1. 测试期仅有 2023-2024，样本外月份较少；
2. 行业中性化使用当前 Tushare 行业标签，不是严格历史行业分类；
3. 组合为 TopN 等权，未做行业、市值和换手约束；
4. 未显式模拟涨跌停、停牌、冲击成本和容量；
5. 财务因子仍较基础，缺少盈利预期、分析师一致预期和公告后漂移等信息。
```

后续可以从三个方向扩展：

```text
1. 加入组合优化：行业约束、市值约束、换手约束；
2. 扩展因子库：盈利预期修正、分析师因子、公告后漂移、残差动量；
3. 改进验证方式：Walk-Forward 滚动训练和更长测试区间。
```
